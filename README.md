Heya! I'm Gan A. I help keep group chats tidy, members happy, and moderation smooth without slowing your team down.

Gan A is a Telegram bot designed to simplify group management. It automatically filters spam, removes unwanted content using AI, manages members, and gives admins the tools they need — all without manual effort.

Built for communities that want clean, friendly, and well-organized chats.

> **Note:** This is a closed-source project. The source code is not available and no direct access to the project is provided.
